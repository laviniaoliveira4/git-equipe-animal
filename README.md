## Descrição

Sistema em Java que demonstra herança e polimorfismo. A superclasse Animal possui nome e idade, e as subclasses Pato e Gato sobrescrevem o método emitirSom() com o som de cada animal. O Main guarda os animais em uma lista do tipo Animal e chama o método de cada um.
